# Missão Bethel Internacional — Beira, Moçambique

Website institucional da **Igreja Missão Bethel Internacional** (Cidade da Beira, Província de Sofala, Moçambique), desenhado com estética editorial minimalista.

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão otimizada de produção:

```bash
npm run build
```

## Onde editar conteúdos e fotografias

- **Textos, horários, cursos, células e ministrações recentes:** [`src/data/churchData.ts`](./src/data/churchData.ts)
- **Fotografias reais da igreja:** pasta `public/images/`
  - `logo-bethel.jpg` — Selo oficial (*Uma família para pertencer*)
  - `culto-beira.jpg` — Fotografia principal da nave na Beira
  - `familia-pastoral.jpg` — Pr. Flávio Andrade, Pra. Cremilde Andrade e família
  - `joias-da-africa.jpg` — Ministério infantil & projeto pré-escolar *Joias da África*
  - `acao-comunitaria.jpg` — Ação social e humanitária na Beira
